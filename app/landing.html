All available endpoints with their access levels and descriptions.

Public

Features
Built for production

Every feature you need to ship a secure, scalable user management system.

🔐
JWT Authentication
Stateless authentication with short-lived access tokens and long-lived refresh tokens.
👥
Role-Based Access
Admin and user roles with fine-grained endpoint protection via dependency injection.
🔄
Refresh Tokens
Secure token rotation stored in PostgreSQL with expiry tracking and revocation support.
⚡
Rate Limiting
Brute-force protection on authentication endpoints with SlowAPI middleware.
📋
Audit Logging
File and terminal logging for all critical actions including logins and deletions.
🗄️
Alembic Migrations
Version-controlled database schema changes with automatic migration generation.
Quick Start
Get started in seconds

Login and start making authenticated requests right away.

bash — login example 
# 1. Login and get your tokens
curl -X POST http://localhost:8000/login/ \
  -d "username=you@email.com&password=yourpassword"

# 2. Use the access token on protected routes
curl http://localhost:8000/users/me/ \
  -H "Authorization: Bearer <access_token>"

# 3. Refresh when access token expires
curl -X POST http://localhost:8000/refresh/ \
  -H "Content-Type: application/json" \
  -d '{"refresh_token": "<refresh_token>"}'
